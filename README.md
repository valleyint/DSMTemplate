# Lab Report LaTeX Template

This repository contains a custom LaTeX class (`labreport.cls`) and a template file (`main.tex`) designed to consistently format laboratory reports. It automates section headings, applies consistent spacing and grey separator lines, and standardizes the title header into a specific grid layout.

## Files Included

* `labreport.cls`: The underlying LaTeX class file containing all custom styling, header generation, and environment definitions.
* `main.tex`: The user-facing document where the report data and text are entered.

## Setup Instructions

1. Place both `labreport.cls` and `main.tex` in the same folder.
2. Ensure any referenced image files (e.g., `sample.jpg`) are also located in this folder.
3. Compile `main.tex` using your preferred LaTeX compiler (such as pdfLaTeX) or a cloud-based editor like Overleaf.

## Document Configuration

The template accepts standard font size options (e.g., `10pt`, `11pt`, `12pt`) directly in the document class declaration. All heading sizes will scale proportionally to this base size.
